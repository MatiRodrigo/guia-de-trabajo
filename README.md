# 🚀 Guía de Git y GitHub para el Equipo

Este repositorio es un espacio de trabajo colaborativo para nuestro equipo. A continuación se detallan los comandos esenciales para trabajar de manera organizada sin sobrescribir el trabajo de los demás.

---

## 🛠️ Configuración Inicial (Solo la primera vez)

Si es la primera vez que usas Git en tu computadora, configura tu nombre y correo (utiliza el mismo mail asociado a tu cuenta de GitHub):

```bash
git config --global user.name "Tu Nombre"
git config --global user.email "tu_email@ejemplo.com"
```
